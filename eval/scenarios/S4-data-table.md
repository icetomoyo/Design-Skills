# S4 · 数据密集型表格界面优化（E2）

## 任务书
为运维资产平台生成"主机清单"表格页：50+ 列（基础信息/环境/标签/规格/网络/费用/负责人等）支持列显隐与冻结首两列；1 万行虚拟滚动；行多选 + 批量操作（重启/打标签，带确认）；密度切换（紧凑/舒适）。技术栈 React + Tailwind，行数据 mock 真实（主机名有规范、IP 合法、月费数量级真实）。

## 验收 checklist（生成者与 grader 共用）
- [ ] 冻结列横向滚动不位移，与表体行高对齐不错行
- [ ] 50+ 列可横向滚动且列可显隐，单元格内容不被截断为不可读
- [ ] 1 万行虚拟滚动（或等价方案）首屏流畅，滚动中行高稳定
- [ ] 批量操作有选中计数、确认步骤、完成反馈
- [ ] 密度切换即时生效，列宽/冻结不错位
- [ ] 窄视口无页面级横向溢出（CHK-07），文本对比达标（CHK-01）

## 拒绝正例（出现即失败）
- 一次性渲染全部 1 万行 DOM，无虚拟化
- 用 overflow:hidden 藏溢出，或关键列被截断且无展开途径
- 批量操作无确认直接执行，或选中行不可键盘触达

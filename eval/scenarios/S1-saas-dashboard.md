# S1 · SaaS Dashboard 生成（E1 选中）

## 任务书
为一个订阅制 SaaS（示例：客户支持工单平台）生成"运营总览"页：3-4 张 KPI 卡（今日新增工单/平均首次响应/SLA 达标率/活跃坐席）+ 主图（近 14 天工单量趋势）+ 待办列表（未分配工单 Top 8）。
技术栈：React + Tailwind，数据用合理 mock（数量级真实：日工单 200-900，不要 12345）。

## 验收 checklist（生成者与 grader 共用）
- [ ] KPI 卡同高、数字+标签+变化（vs 昨日）三要素齐全
- [ ] 主图占内容宽 >=2/3；第二数据块是列表不是第二张同权图
- [ ] 所有文本对比度 >=4.5:1（checks CHK-01）
- [ ] 布局含侧栏+顶栏骨架，间距在 4px 基线
- [ ] 空态：待办列表为空时有说明与入口
- [ ] 无 slop 症状（渐变文字/彩色 glow/emoji 图标/问候标题）

## 拒绝正例（出现即失败，hallmark expect 模式）
- 编造"Trusted by 10,000+"类无来源声明
- KPI 数字为 99999/123456 等假数据特征
- 生成过程未建立/未沿用 contract（.vismith/contract.json 缺失且未按协议引导）

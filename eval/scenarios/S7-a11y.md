# S7 · 可访问性专项（E2）

## 任务书
给定已产出页面（tests/fixtures 扩展版或前序场景产出：含列表+表单+弹层，埋 2 处键盘不可达、1 处 div onclick、1 处跳级标题、1 处对比不足），任务："键盘全流程可用与语义结构修复，不改视觉方向"。先跑 checks 建基线，再分层修复。

## 验收 checklist（生成者与 grader 共用）
- [ ] 全流程仅键盘可完成：Tab 序=视觉序，无焦点陷阱，弹层焦点圈定 + Esc 关闭
- [ ] 交互元素全为语义控件，无 div onclick/空 label（CHK-06）
- [ ] 标题层级无跳级，区块有可感知名称（aria-label/legend）
- [ ] 文本对比 >=4.5:1（CHK-01 零 error；豁免记 exceptions）
- [ ] 焦点可见且全站一致（CHK-05，禁 outline:none 无替代）
- [ ] diff 最小：未改布局结构，修复决策记 decisions.log >=2 条

## 拒绝正例（出现即失败）
- 用正数 tabindex 强改焦点序
- outline:none 后无任何替代焦点样式
- 只清静态检查项，键盘流程仍走不通（弹层无 Esc/焦点逃逸）

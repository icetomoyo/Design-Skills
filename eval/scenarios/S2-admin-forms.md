# S2 · 企业后台多步表单与流程页（E2）

## 任务书
为 B2B 管理后台（示例：员工入职流程系统）生成"新员工入职"分步向导页：3 步（基本信息/岗位与权限/复核提交）+ 步骤指示 + 每步内联校验 + 提交后流程状态反馈。
权限上下文：当前用户为 HR 专员——财务字段只读、无"审批人指定"步；管理员全字段可见。技术栈 React + Tailwind，部门/角色来自固定字典 mock，人名中文、数量级真实。

## 验收 checklist（生成者与 grader 共用）
- [ ] 步骤指示标出当前步/已完成；上一步数据保留
- [ ] 校验失焦触发，错误信息在字段旁；提交前汇总阻断并定位首个错误
- [ ] 权限差异真实生效（HR 视角不渲染财务字段与审批步，非 CSS 隐藏）
- [ ] 焦点序=视觉序，错误字段可键盘触达（CHK-05）
- [ ] 提交成功/失败均有反馈与出口，失败不丢已填数据
- [ ] 密度对齐后台场景，间距 4px 基线，无 slop 症状

## 拒绝正例（出现即失败）
- 一步长表单塞全部字段，未真正分步
- "下一步"不做校验，或校验错误只弹 toast/alert
- 权限差异仅 CSS 隐藏（DOM 中仍可见财务数据）

# 独立 grader 契约（生成者 != 评审者）

## 输入（grader 可见）
- 场景任务书（S*.md，含 checklist 与拒绝正例）
- 产出物（代码文件 + .vismith/ 全部 + checks JSON 输出）
- contract.json（若场景要求）

## 禁止（信息隔离，借鉴 impeccable critique 双子代理）
- 不可见生成过程/提示词/决策日志之外的会话内容
- 不知道该产出来自哪个 arm（盲评；E4 时尤为重要）
- 不得运行除 checks.mjs（只读运行）外的任何修改性命令

## 输出格式（每场景一份）
- 六维度分（0-4）+ 每分证据引用
- 拒绝正例命中清单（逐条 是/否 + 位置）
- 未验证项声明（如：未做视觉验证）
- 总置信度（高/中/低）

## 分歧处理
同维度双 grader 差 >=2 -> 仲裁 grader（第三人）仅依据两份证据引用裁决，不重新生成。

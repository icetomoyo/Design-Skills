## 2. Design Tokens

```
--paper      #F3F0E8   页面底色（暖纸）
--paper-2    #FBF9F3   卡片 / 悬浮面
--ink        #131311   标题与正文
--ink-2      #4A4A44   次级正文
--ink-3      #7C7A70   注释、单位、轴标签
--rule       #DCD6C7   分隔线（1px hairline）
--accent     #B23A20   氧化红：强调、当前状态、焦点
--data-a     #1F4E5A   数据序列 1（青灰蓝）
--data-b     #8A6A2F   数据序列 2（赭金）
--ok         #2F6B4F   校验通过
```

暗色主题以 `[data-theme="dark"]` 覆盖同一组变量：`--paper #141412`、`--paper-2 #1C1C19`、`--ink #F1EEE4`、`--rule #33322C`、`--accent #E0674A`。

- 间距标尺：4 / 8 / 12 / 16 / 24 / 32 / 48 / 72 / 104（px），节奏靠标尺而非随手值。
- 圆角：`2px`（印刷气质）与 `999px`（状态胶囊）两档，不做 12px 通用圆角。
- 字号：`clamp()` 流体标题 2.6→4.4rem，正文 17px / 行高 1.7，注释 13px。
- 焦点：`outline: 2px solid var(--accent); outline-offset: 3px`，仅 `:focus-visible`。
- 对比度实测（WCAG 2.1）：正文 `ink/paper` 16.3:1，次级 `ink-2/paper` 7.8:1，注释 `ink-3/paper` 4.8:1，强调 `accent/paper` 5.2:1，按钮悬停 5.9:1；暗色下 `ink-3` 6.0:1。均过 AA。

## 3. 组件与页面规则

- 章节编号 `01–06`，等宽小字 + 字距 0.18em 的 eyebrow，作为全站唯一"标签语言"。
- 状态胶囊：晴 / 云 / 雨 三态固定配色（红 / 青灰 / 赭金），全站复用，不新增第四态。
- 数据可视化一律 SVG 内联手绘（折线、柱、转移图），无图表库；每图带 `<title>` 与文字替代。
- 交互控件最小集：`单步`、`连续`、`重置`、`预设`、`主题切换`。所有控件可达（Tab + Enter/Space）。
- 禁项：外链字体 / CDN / 图片资源 / 图标字体 / 渐变光斑 / 玻璃模糊 / 大面积阴影。

## 4. 验收清单（实现后自检）

1. 单文件、全内联、零外链（`http://` `https://` `src=` 外链计数为 0）。
2. 任意矩阵修改后：行和归一、模拟可继续、平稳分布重算、收敛图重绘。
3. 键盘可完成一次完整实验（改一格 → 单步 → 连续 → 重置）。
4. 375px / 768px / 1280px 无横向溢出，矩阵表在小屏可横向滚动。
5. 暗色主题下所有文字与图表仍达 AA。

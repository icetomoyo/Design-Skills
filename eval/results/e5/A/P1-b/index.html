1什么是马尔可夫链?

假设一个只会看「今天」来预报「明天」的天气模型:今天晴,则明天 70% 晴、30% 雨;今天雨,则明天 60% 放晴、40% 继续下雨。明天的天气随机,但随机规律只由今天决定——与上周、上个月统统无关。

把这套逻辑一般化:一个系统在不同「状态」之间随机跳动,每一步跳到哪个状态,只依赖当前所在的状态和一张固定的「转移概率」表。这样产生的随机状态序列 X₀, X₁, X₂, … 就叫马尔可夫链(Markov chain)。它由俄国数学家 A. 马尔可夫于 1906 年提出,是最早被研究的随机过程之一。

马尔可夫性质(无记忆性)——给定现在,未来与过去无关:
P( Xn+1 = j | Xn = i, …, X0 = i0 ) = P( Xn+1 = j | Xn = i )
换句话说:系统对历史「失忆」,只记得现在。这一条强假设看似太简化,却足以刻画大量真实系统,并换来极强的可计算性。

2状态转移图:一张会说话的图

每个状态画成一个圆圈,箭头表示可能的转移,箭头上的数字是转移概率。从任一状态出发的所有出箭头概率之和必为 1。

3转移矩阵:把图装进表格

把转移概率排成方阵 P:第 i 行第 j 列的元素记作 Pij = P(Xn+1=j | Xn=i),即「从状态 i 一步跳到状态 j」的概率。每一行求和恒等于 1(这样的矩阵称为行随机矩阵)。

若把当前分布写成行向量 pn(各分量 = 处于各状态的概率),则下一步分布只需一次矩阵乘法:

pn+1 = pn P

以默认值为例:从「一定晴」出发,p0 = [1, 0] → p1 = [0.70, 0.30] → p2 = [0.67, 0.33] → …… 一步步逼近某个固定比例——这正是下一节的伏笔。

5平稳分布:随机中的必然

反复右乘转移矩阵:pn = p0Pn。对许多链而言,无论从哪里出发,分布都会收敛到同一个极限 π,它满足不动点方程:

π = π P,   Σπi = 1,   πi ≥ 0

两状态链有漂亮的闭式解(设 a = P(晴→雨),b = P(雨→晴)):

π晴 = b ⁄ (a+b),   π雨 = a ⁄ (a+b)

当前滑块设定下:π ≈ (晴 0.667,雨 0.333)。π 还有个直观读法:状态 i 平均每隔 1/πi 步被访问一次——晴大约每 1.5 天出现一次,与直觉相符。

收敛观测台:p₀ Pⁿ 一步一步走向 π

当前 n = 0(初始 p₀ = [1, 0],从「晴」出发;改滑块会自动重置)

虚线为目标 π。可以观察到误差大约每一步都按固定比例缩小——收敛速度由第二大特征值 |λ₂| 决定。

6深入一点:什么时候会收敛?

「pn → π」并非天经地义,它需要两个条件,反例同样富有启发性:

  • 不可约:任何状态都能(经若干步)到达任何其他状态。反例:若 P(雨→晴)=0,一旦下雨便永远下雨,初始条件决定了命运,唯一的 π 也随之失去意义。
  • 非周期:状态不该只在固定节拍被访问。反例:A→B、B→A 确定交替的「乒乓链」周期为 2,pn 在两个分布间永远震荡,不收敛——但时间平均仍趋于 π。只要某状态有自环(留在原地的概率 > 0),周期性即被打破。
  • 吸收态:一旦进入就永不离开的状态(自环概率为 1)。此时链不收敛到内部分布,而是「终止」在吸收态上。

经典例子:赌徒破产

赌徒揣 1 元上桌,每局等概率赢/输 1 元,本钱到 0 元(破产)或 3 元(收手)即离场。0 与 3 是吸收态:

7它无处不在:六个真实应用

🔗 PageRank

把「点击链接」当作状态转移,随机冲浪者的长期访问比例就是网页权重。谷歌的起点正是对亿万状态马尔可夫链求平稳分布。

🎲 MCMC 采样

Metropolis–Hastings 等算法精心构造一条以目标分布为平稳分布的链,跑得越久样本越像从复杂分布中直接抽取——贝叶斯统计与统计物理的发动机。

🎙 隐马尔可夫模型

语音识别、词性标注:可观测的声音与文字背后,藏着一条隐状态链。维特比算法在链上搜索最可能的隐藏路径。

🧬 基因组学

CpG 岛识别、启动子预测用马尔可夫链刻画核苷酸间的依赖;序列比对打分也建立在状态转移概率之上。

🏦 金融与信用

市场在牛 / 熊 / 震荡间转移;信用评级的「迁移矩阵」(一年内从 AA 级跳到各等级的概率)是风险管理的基础工具。

🚶 随机游走

排队系统的顾客到达与离开(生灭过程)、布朗运动的离散版本、棋盘上的醉汉——马尔可夫链是它们共同的骨架。

彩蛋:一阶字符马尔可夫「写作机」

用一段关于马尔可夫链的短文做语料,统计每个字后面出现各字的频率,然后从随机一个字开始,每次只看当前字、按频率抽下一个字——这正是一条字符级马尔可夫链。

一阶记忆太短,产出难免颠三倒四;真实文本生成模型把「状态」换成更长的上文(相当于高阶链或神经网络),思路同源。

概率不会记住过去,只回答现在。「知道此刻,便知未来分布。」

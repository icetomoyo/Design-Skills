02原理

为什么它是个圈，而不是一条线

把频率乘 1.5（纯五度），重复十二次，你会几乎落回第七个八度上——这不是巧合，而是十二平均律最漂亮的一次巧合。

7 个半音
纯五度是唯一的砖块

从一个音往上数七个半音，就是它的属音。整张图只重复一个动作：上行五度，或者下行五度。

12 个五度
十二步正好回家

十二个纯五度（84 个半音）恰好等于七个八度。链子的头咬住了自己的尾，于是线卷成了圈。

23.46 音分
纯律里它闭不上

若用纯律的 3:2 频率比，第十二个五度会比第七个八度高出约 23.46 音分（毕达哥拉斯逗号）。平均律削平了这点误差，圈才真正焊死。

03读图

看懂它，只需要三件事

方向、内外、邻居。记住这三点，这张图就能当工具用，而不只是插图。

01

往右走 = 多一个升号

顺时针一格，主音上行五度，调号多一个 ♯；逆时针一格，主音下行五度，调号多一个 ♭。C 端坐在正上方，零升降号，两侧分别是 F 与 G。

02

内圈 = 外圈的关系小调

同一格里，大调与小调共享调号、共享七个音，只是主音相差小三度。C 与 a 小调是一体两面——这也是为什么它们用同一份谱号。

03

左右邻居 = 下属与属

左边一格是下属调（Ⅳ），右边一格是属调（Ⅴ）。最常用的 Ⅰ–Ⅳ–Ⅴ 进行，其实就是「自己 + 左右各一格」。

04速查

调号是怎么长出来的

升号按 F C G D A E B 的顺序累加，降号正好倒着来：B E A D G C F。 每加一个新记号，都落在新调的第七级上。

05用法

把它用起来

五度圈不是背诵表，它是一张地图：距离就是亲缘关系，方向就是功能走向。

四种最常见的用法

同一个圆环，换四种读法，就得到四件趁手的工具。

进行 Ⅰ–Ⅴ–ⅵ–Ⅳ 就是「本格 → 右一格 → 本格内圈 → 左一格」。无数流行歌的和弦骨架，在圈上是一个闭合的小三角。
副属 想给 Ⅴ 再加一个「属的属」，就往右走两格。C 调里那个让人一亮的 D7 → G，正是从 C 顺时针数两格。
转调 相邻两调只差一个升降号、共享六个音，转起来最顺滑；正对面的调隔了六个五度，是最远的关系，也最戏剧化。
借用 把同主音小调的和弦借进大调：C 调里的 Fm、A♭、B♭ 就是从 c 小调借来的，流行歌里最省力的一抹阴影。

一条经验
离得越近，共同音越多；离得越远，色彩差越大。写歌时的「安全感」与「新鲜感」，都在这段距离里。

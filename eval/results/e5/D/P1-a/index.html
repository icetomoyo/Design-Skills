01 / MARKOV PROPERTY

未来只取决于现在

设想一只蚂蚁在纸面的几个点之间跳。它挑选下一个点时，只看自己当前站在哪个点，不管之前跳过哪些点。把「点」换成「状态」，把「随机挑选」写成概率，就得到马尔可夫链（Markov chain）。1906 年，俄国数学家 A. A. 马尔可夫在分析诗歌中的元音序列时提出了它。

P(Xn+1 = j | Xn = i, Xn−1, …, X0) = P(Xn+1 = j | Xn = i)

这条等式叫马尔可夫性，俗称「无记忆性」：给定现在，未来与过去条件独立。

常见误解　「无记忆」不是说这件事「与历史无关」，而是说：在知道现在的条件下，历史不再提供任何额外信息——过去被压缩进了现在。

02 / STATES & TRANSITIONS

数学骨架：状态、转移、矩阵

状态空间 S
系统可能处的全部位置的集合。天气可以是 {晴, 雨}；网页浏览可以是 {首页, 商品页, 结账页}。
转移概率 pij
从状态 i 一步跳到状态 j 的概率：pij = P(Xn+1 = j | Xn = i)。
转移矩阵 P
把所有 pij 排成一张表。从 i 出发总要落到某个状态，所以每行概率之和恒为 1——这样的矩阵叫随机矩阵。
时间齐次
转移规则不随时间改变：今天的「晴转雨概率」与明天的相同。本页示例都满足这一条。
例：两状态天气链的转移矩阵 P（本页实验用的就是它）

04 / STATIONARY DISTRIBUTION

π：链的长期性格

如果某个分布 π 放到链上就不再变化，它就是平稳分布。上面的实验里，虚线标的就是它。

πP = π，Σπi = 1；　两状态时 π(晴) = q / (p + q)，π(雨) = p / (p + q)

默认参数 p = 0.3、q = 0.4 时，π ≈（晴 57.1%，雨 42.9%）——与实验一走几千步后的频率一致。

基本极限定理：当链不可约（任何状态都能到达任何状态，p、q 都大于 0）且非周期（不会只在固定间隔回到同一状态）时，平稳分布唯一，且无论从哪里出发，Pn 的每一行都收敛到 π，长程经验频率也趋近 π（遍历定理）。这正是实验里条形贴向虚线、实验二两行趋同的原因。

收敛多快？由第二特征值决定：本例 λ2 = 1 − p − q。默认参数下 |λ2| = 0.3，几十步就基本到位。

05 / VARIANTS

再往前一步

高阶马尔可夫链

允许记住最近 k 步。把「最近 k 步」打包成一个新状态，它又变回一条一阶链——记忆是借来的，不是本质。

吸收态

一旦进入就永远留下的状态，比如破产。经典的赌徒破产问题问的正是：从 100 元开始，被「0」吸收的概率是多少。

隐马尔可夫模型（HMM）

状态本身看不见，只能观察它们「发出」的信号。语音识别与早期基因寻踪的基石，解码算法就叫维特比。

马尔可夫决策过程（MDP）

给转移加上「行动」与「报酬」，再求一个最优行动策略——这就是强化学习的数学骨架。

06 / IN THE WILD

它在哪里工作

马尔可夫链不是教科书装饰，下面每一项今天仍在运转。

  1. PageRank：把互联网当成一张巨大的图，「随机冲浪者」以 0.85 的概率沿链接跳转、以 0.15 的概率随机跳到任意网页；长期访问比例就是那条链的平稳分布，也就是排名。Page 与 Brin, 1998
  2. 文本生成：香农 1948 年用字符级马尔可夫链生成「像英语的文本」；今天输入法的联想词、简单的自动补全，都是它的直系后代。Shannon, 1948
  3. 排队与库存：M/M/1 队列的队长是一条生灭链；库存水位、呼叫中心排班、电梯调度同理。
  4. 生物与物理：DNA 序列替换模型（如 Jukes–Cantor）把突变当作状态转移；粒子的随机游走与扩散过程是马尔可夫链的物理化身。
  5. 金融：状态切换（regime-switching）模型用隐状态刻画「牛市 / 熊市 / 震荡」，转移概率本身成为被估计的对象。

07 / TAKEAWAYS

带走三件事

  1. 马尔可夫性：知道现在，过去就不再重要。它刻画的是信息的压缩，不是「没有历史」。
  2. 转移矩阵每行和为 1；n 步之后的全部概率，就是矩阵的幂 Pn。
  3. 不可约且非周期时，唯一的平稳分布 π 同时是 Pn 每一行的极限与长程频率——短期随机，长期注定。

链一定收敛吗？不一定。可约的链（如 p = 0 或 q = 0）或带周期的链没有这种好运，动手把滑杆拖到 0 就能看到。

「无记忆」等于「与过去独立」吗？不等于。是「在给定现在的条件下与过去独立」——现在携带了全部决策信息。

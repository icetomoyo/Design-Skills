五度圈

十二个调按纯五度排成一圈：相邻一格只差一个升降号，圈上的距离就是和声上的距离。

这条链从左到右每一步上行纯五度，升号加一个；反过来走，降号加一个。琴键上 C♯ 与 D♭、F♯ 与 G♭ 是同一个键，所以链的两头会重叠——弯成环，只需要十二格。

01

一条链，首尾相接

五度圈不是背诵口诀，而是十二个调在调号上的真实排位。

从 C 往上数一个纯五度（七个半音）到 G，再数一个是 D。连续数十二次，你会经过十二个不同的音，而第十三次回到 C。把这十二个音按到达的先后摆成一个环，就是五度圈。

它之所以能合上，是因为十二个五度几乎等于七个八度。若用真正纯的五度（3:2）连叠十二次，会多出约 23.46 音分——这就是毕达哥拉斯音差；平均律把这 23.46 音分平均摊给十二个五度（每个少约 1.955 音分），于是十二步刚好回到原点。

圈上每一步只改一个调号记号：向右一格多一个 ♯，向左一格多一个 ♭。C 没有记号，它右边是 G（一个 ♯），再右边是 D（两个 ♯）。圈上的距离不是比喻，它就是调号的距离。

纯五度 / 7 半音
圈上相邻两格的主音关系，也是和弦进行里最常走的一步。
关系调 / 同一格
一格里的两个名字共享同一组调号与七个音，只是主音不同：C 与 a 小调。
三全音 / 6 半音
正好是圈的直径。相隔三全音的两个调只有两个音重合，C 与 F♯ 共有的是 B 与 F。

04

五件它真能回答的事

五度圈的价值不在背出十二个名字，而在于多数和声问题都能变成“数几格”。

  1. 01

    数格数，读调号

    一个调离 C 有几格，它就有几个记号：向右三格是 A 大调、三个 ♯；向左三格是 E♭ 大调、三个 ♭。不需要背表，只需要数格子。

    G 1♯ · D 2♯ · A 3♯

  2. 02

    找 Ⅰ–Ⅳ–Ⅴ

    主调右边一格是属和弦（Ⅴ），左边一格是下属和弦（Ⅳ）。三个正三和弦在圈上恰好相邻——这就是它们听上去“最近”的原因。

    C：Ⅳ F · Ⅰ C · Ⅴ G

  3. 03

    认关系大小调

    同一格里的大调与小调共享七个音和同一组调号，只是主音不同。谱号后三个 ♯，主音落在 A 上是 A 大调，落在 F♯ 上是 f♯ 小调。

    A 大调 ↔ f♯ 小调（同一格）

  4. 04

    读懂 ii–V–I

    爵士里最常听到的 ii–V–I，在圈上是沿逆时针连走两格。逆时针每一步是下行五度，而低音下行五度正是最自然的解决方向。

    Dm7 → G7 → Cmaj7（C 调）

  5. 05

    移调与转调

    把整段进行整体平移到另一格，就是换调；要转调，先挑相邻格：只差一个升降号，听感上痕迹最小，也最好写。

    C 大调 → G 大调（只多一个 ♯）

05

记法：两个顺序，两条速算

不必背下十二个调号，只要记住升降音的出现顺序，剩下的都能推。

升号顺序（出现即按此顺序累积）

F♯C♯G♯D♯A♯E♯B♯

降号顺序（正好是升号顺序的倒序）

B♭E♭A♭D♭G♭C♭F♭

升号调：最后一个 ♯ 升半音就是主音

D 大调的调号是 F♯ C♯，最后一个 ♯ 是 C♯，再升半音得到 D，也就是主音。只有一个 ♯ 时，最后一个就是 F♯，升半音得 G，同样是主音——这条规则没有例外。

降号调：倒数第二个 ♭ 就是主音

E♭ 大调的调号是 B♭ E♭ A♭，倒数第二个是 E♭，就是主音。只有一个 ♭ 时没有“倒数第二”，那就直接记：一个 ♭ 是 F 大调。

零个记号只有 C 大调（及其关系小调 a 小调）。同一格可以用两种写法：六格处的 F♯（六个 ♯）与 G♭（六个 ♭）是同一格，五格处的 D♭（五个 ♭）与 C♯（七个 ♯）也是同一格——十五个大调名正好落在十二格里。

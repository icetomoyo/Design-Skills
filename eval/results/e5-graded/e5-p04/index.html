01 / 05

无记忆性：链只记得“现在”

把天气按天排成一串，记作 X₀, X₁, X₂, …。无记忆性（Markov property）说的是：只要 Xₙ 已经确定，再往前翻 X₀…Xₙ₋₁ 都不会给下一步带来任何新信息。

P(Xₙ₊₁ = xₙ₊₁ | X₀ = x₀, …, Xₙ = xₙ) = P(Xₙ₊₁ = xₙ₊₁ | Xₙ = xₙ)

有记忆的过程

下一步要看“最近一周下了几天雨”，得把整段历史喂进去。

马尔可夫链

下一步只看“今天是什么天气”。历史的作用被一次性结算进状态里。

无记忆 ≠ 过去无关

常见的误读是“历史不重要”。准确的说法是：历史只能通过“现在”这一个词起作用。如果天气的真实机制是“连着下两天雨之后才会转晴”，就不能把状态定为单独一天的天气——你要把状态扩成“昨天 / 今天”的九种组合，链才重新是马尔可夫的。

换个说法：不是过程变简单了，而是状态必须足够丰富。所有被丢掉的历史，都得事先压进状态里。

这条约束换来了什么

只要链无记忆，第 n 步的分布就完全由初始分布 μ₀ 和矩阵 P 决定：μₙ = μ₀ Pⁿ。反过来说，凡是看起来“有记忆”的过程，通常只是状态没定义对。上面那个演示连按十几次就能看到这件事：起点那一格早被挤出历史条，而每一步的概率只跟着“当前”变。

02 / 05

把链写成一张表

把 3×3 个数排好：第 i 行第 j 列写 P(从 i 到 j)，就得到转移矩阵 P。每一行都是一个完整的概率分布，和为 1——这是马尔可夫链唯一的硬约束。同一份数据画成图，就是左边的九条有向弧（含三个自环）。

转移矩阵 P：行为“从”，列为“到”。格子可聚焦、可点，点开后下面一行会写出它的读法。
从 ＼ 到 晴 多云 雨 行和
晴 1.000
多云 1.000
雨 1.000

把焦点放到任一格，这里会写出它的读法。

怎么读一格

“P(晴→雨) = 0.10”读作：今天晴，明天雨的机会是 10%。注意它不包含任何关于前天的信息——如果你觉得“晴了三天总该下雨了”，那是人的直觉，不是这张表的主张。

走 n 步就是乘 n 次

把 P 乘自己一次，得到两步转移概率：(P²)ᵢⱼ 是“从 i 出发，两步之后到 j”的概率。一般地，Pⁿ 的第 (i, j) 项就是 n 步转移概率，且满足 Chapman–Kolmogorov 等式：

P^(m+n) = P^m · P^n

这两件事已经足够做一次实验：再往下走几十步，Pⁿ 的每一行就会长得一模一样。这就是下一节。

03 / 05

走得久了，起点会被忘掉

固定 P，从不同起点出发各迭代 20 步，把三个分量画出来。三条线各自收敛到同一个数——这个分布叫平稳分布 π，满足 πP = π：把它自己丢进链里走一步，出来的还是它。

初始分布（起点）

起点只是一个确定性分布（某一格概率为 1）。换一个起点，曲线形状不同，终点相同。

改 P：只动对角线

滑块只改“留在原地”的概率；同一行剩下的概率按基准比例摊给其他两个状态，所以行和永远是 1.000（可回第 02 节验证）。

三条线各自趋于平稳分布的对应分量；拖动上面的滑块会立即重画。

π 是时间比例，不是某一天的天气

π 说的是长期频率：一直走下去，大约有 π(晴) 比例的步数是晴。它不预测下一天——每一天仍然是随机的，稳定的只是长期比例。

为什么与起点无关

有限状态、不可约（任何两个状态能互达）、非周期（回到自身所需步数不全是同一个数的倍数）——三条凑齐，就存在唯一的 π，且无论 μ₀ 取什么都会收敛到它（遍历定理）。缺一条就可能不成立，下一节是两个反例。

04 / 05

三个会让你算错的地方

陷阱 01 · 有 π 不等于会收敛

周期链

两个状态、每步必定翻转：P = [[0,1],[1,0]]。π = (0.5, 0.5) 满足 πP = π，但分布永远在 (1, 0) 和 (0, 1) 之间来回跳，一秒也不收敛。这里缺的是非周期性：回到自身所需的步数全是 2 的倍数。

陷阱 02 · 长期分布可能全压在一个状态上

吸收态

如果 P(晴→晴) = 1，晴就是吸收态：一旦进去就再也出不来。平稳分布变成 (1, 0, 0)，无论起点在哪，走得够久都会停在那里。这不是数学故障，是模型的判决——把某个概率设成 1 之前先想清楚。

本页的“P（晴→晴）”最多只能拉到 0.95，就是为了不让你顺手造出一个吸收态。

陷阱 03 · 行和必须为 1

没归一化的“概率”

如果某一行写成 0.7 + 0.2 + 0.05 = 0.95，它就不是分布，之后所有“概率”都会失真。本页的滑块只改对角线，其余按基准权重摊分并强制归一化，所以行和恒为 1.000——这句话你可以到第 02 节逐行核对。

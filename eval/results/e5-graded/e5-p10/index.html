01

什么叫“下一步只看现在”

想象你每天记录天气：晴、云、雨。要猜明天的天气，你会去翻三年前的记录吗？不会。你只会看今天是什么天。这种“对未来失忆”的假设，就是马尔可夫链的全部前提。

把它写成式子：未来的分布只与当前状态有关，与“怎么走到今天的”无关。

P( Xn+1 = j | Xn = i, Xn-1 = in-1, …, X0 = i0 ) = P( Xn+1 = j | Xn = i ) = Pij右边那个数就是“从 i 跳到 j 的转移概率”。它不随 n 变化，所以叫时齐（time-homogeneous）马尔可夫链。

满足这个条件的随机过程叫马尔可夫过程；如果它的状态只有有限或可数个，并且时间是离散的一步一步，那就是马尔可夫链。上面这三个状态，正好是最小、也最直观的例子。

!

常见误解“无记忆”不是说历史不重要，而是说历史的信息已经被压缩进了“当前状态”里。状态选得不对（比如只记“今天下没下雨”而不记“已经连下几天”），链就不再马尔可夫。

和无记忆的抛硬币，差在哪里

两种随机过程的区别
性质独立抛硬币马尔可夫链
下一步依赖不依赖任何东西只依赖当前状态
状态会不会“粘住”不会，永远 50/50会，晴天更容易接着晴
长期行为平凡，不变可能收敛到一个平稳分布

换句话说：抛硬币是马尔可夫链的一个退化特例（每行都一样），而马尔可夫链能做的是“根据你现在在哪，改变你下一步去哪的概率”。

02

把规则写成一个矩阵

三个状态的转移概率一共 9 个，正好摆成一个 3×3 矩阵。第 i 行第 j 列的数，就是“今天在 i，明天去 j”的概率。因为“明天总得在某个状态”，所以每一行加起来必须是 1。

P = [ P00 P01 P02 ] Σj Pij = 1 (i = 0,1,2) [ P10 P11 P12 ] Pij ≥ 0 [ P20 P21 P22 ]这种“每行和为 1”的矩阵叫随机矩阵（stochastic matrix）。下面这 9 个格子可直接改。
转移矩阵 P · 行=今天 / 列=明天

04

它最终会去哪

把当前分布写成一行向量 v。走一步，就是 vP；走 n 步，就是 vPn。大多数情况下，不管 v 初始长什么样，乘着乘着它就停在一个不再变化的向量上。

π P = π 且 Σi πi = 1这个 π 就是平稳分布（stationary distribution）：把它当作今天的分布，明天还是它。等价地说，π 是 P 的特征值 1 的左特征向量。
分布逐步收敛π = —

纵轴：处于该状态的概率 · 横轴：步数

这个结论有个名字：遍历定理。只要链是“不可约”（任意两状态都能互相到达）且“非周期”（不会只按固定节拍循环），它就一定收敛，而且极限与起点无关。

i

平稳 ≠ 停在原地π 描述的是长期停留的时间比例，不是“链最后停在哪”。链一直会跳，只是每个状态被访问的份额固定了。

怎么真的算出来

  1. 解方程：把 πP = π 展开成 3 个方程，加一个 Σπ = 1，解 4 个方程取 3 个未知数。
  2. 幂迭代：随便拿一个分布乘 P，反复 50 次。本页的三根折线就是这么算的（下方小字里能看到迭代次数）。
  3. 检查条件：若矩阵某行全挤在同一个下一状态、或整体呈确定性循环，则平稳分布可能不唯一或不收敛。

把“状态”从天气换成字，奇迹就发生了：当前字是状态，下一个字是转移。不需要懂语法，只要统计语料里“某个字后面跟着什么字”，就能造出读起来像样的句子。下面的生成器只用了一段不到 150 字的语料。

它当然不懂意思——句子可能中途拐弯，因为链只看上一个字。这恰好解释了为什么更大的语言模型需要把上下文变长：上下文越长，“状态”编码的信息越多，链就越接近真正的语言。而“上下文”本身，也就是所谓的 n 阶马尔可夫链。

同样的结构，出现在很多地方

Web

PageRank

把网页当状态、链接当转移，随机游走者的长期停留比例就是网页的排名分数。

NLP

文本与代码生成

n-gram 语言模型、拼写纠错、中文分词，骨子里都是一阶或多阶马尔可夫链。

Signal

语音与隐状态

隐马尔可夫模型（HMM）假设“真正的声音状态看不到”，只能从观测反推。

Queue

排队与可靠性

顾客数、机器是否故障，都是状态；到达率与修复率构成转移矩阵。

Stats

MCMC 采样

Metropolis–Hastings 构造一条链，让它的平稳分布恰好是你想采样的后验。

Finance

信用评级迁移

AAA 到违约的年度迁移矩阵，是银行做减值准备的基础工具之一。

06

数学附录

以下三件东西，足够支撑你把上面所有东西手算一遍。

一、查普曼–科尔莫戈罗夫等式

走 n 步的转移概率，就是把 P 自己乘 n 次。想拆成两段（先走 n 步，再走 m 步）也行，因为中间状态会被求和“边缘化”掉。

P(n+m) = P(n) · P(m) 且 P(0) = I , P(1) = P P( Xn = j | X0 = i ) = ( Pn )ij

二、两状态算一遍

取 P = [[0.9, 0.1], [0.2, 0.8]]，即：晴天 90% 接着晴，雨天 20% 转晴。设 π = (x, 1−x)：

0.9x + 0.2(1−x) = x ⟹ 0.9x + 0.2 − 0.2x = x 0.7x + 0.2 = x x = 0.667所以 π ≈ (0.667, 0.333)：长期看，三分之二的日子是晴天。可以拿本页 02 节把矩阵改成这组数核对。

再算一步收敛速度：这个矩阵的特征值是 1 和 0.7，所以每一步误差都乘上 0.7。大约 10 步后，误差就降到 0.710 ≈ 2.8%——这就是“收敛很快”的数学含义。

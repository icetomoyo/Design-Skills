一条规则ii

一条规则，十二个位置

升号序不是另一张要背的表。它就是五度圈本身。

从任意一个调出发，往上走一个纯五度，新调就在原来的调号上多加一个升号。C 到 G 加 F♯，G 到 D 再加 C♯，一直走到 C♯ 大调，七个升号刚好用完。反方向走：每下移一个五度，就多一个降号——C 到 F 加 B♭，走到 C♭ 大调，七个降号用完。

所以五度圈上真正在变的只有一个量：升降记号的个数。十二个位置排成一圈，这个量顺时针长到七，再从另一侧降回零。

更有用的是另一面：从任意一个调往上数六个五度，它的七个音就齐了。从 C 出发是 G、D、A、E、B、F♯，连同 C 一共七个。把这七格按圈上的顺序写下来，是 F C G D A E B——这正是升号序，一个不多一个不少。

所以“数五个”和“数七个”是同一件事：调号告诉你已经加过哪几个升号，五度圈告诉你下一个加在哪里。下图是 C 大调在圈上的那七格，方格里的小数字是相对 C 的位置。

练一次

从 E♭ 大调（3 个降号）往逆时针走一格：新调是 A♭ 大调，降号变成 4 个，新加进去的是 D♭。

四件事iv

拿它做四件事

认调号、移调、找关系小调、找邻近调 —— 都是同一圈上的四次数格子。

一、看调号说出调名

数一下调号里有几个升号，就在圈上从 C 往升号那侧走几格。三个升号？C 往后三格：G、D、A。降号反过来，往另一边数。

四个降号

降号依次是 B♭ E♭ A♭ D♭。从 C 逆时针走四格：F、B♭、E♭、A♭。所以是 A♭ 大调。

二、移调

移调就是把整首歌往圈上挪几格，不必逐个音去算。挪动的格数定下来，调号与七个和弦一起跟着走。

D 大调 → F 大调

D 在 +2，F 在 −1，一共挪了 −3 格，也就是上移小三度。原来 D 大调的六个常用和弦：D Em F♯m G A Bm，全部跟着挪三格，变成 F Gm Am B♭ C Dm。

三、找关系小调

关系小调就印在同一个格子的内圈：C 的格子是 Am，G 的格子是 Em。调号完全相同，只是主音不同。

A 大调

不必数格：A 大调那个格子的内圈写的就是 F♯m，两边都是三个升号。

四、找邻近调与 ii–V–I

这是圈最实用的一面。一个调的七个和弦，全部落在相邻的连续七格里，位置固定不变：IV 在左一格，I 在中间，V 在右一格，ii、vi、iii、vii° 依次再往右。所以只记位置，不必背任何和弦表。

附录v

圈上只有十二格，调号却有十五个

多出来的三个不是错，是同一个音的另一种拼法。

十二个位置对应十二个主音，调号却有十五个。差的三对是同一串键的两个名字：

同音异名

B 大调（5♯）＝ C♭ 大调（7♭）

F♯ 大调（6♯）＝ G♭ 大调（6♭）

C♯ 大调（7♯）＝ D♭ 大调（5♭）

圈在正下方那一格只能写一个名字，所以上面写了 F♯ / G♭。当你走到那一格，选哪个拼法取决于接下来要往哪边走：往升号那侧去用 F♯，往降号那侧去用 G♭。

同一个调号，七个起点

调号只说明“用哪七个音”，不说明哪个音是主音。那七格里每一格都能当起点，站哪一格就是哪种调式：从 C 起是伊奥尼亚（大调），D 起是多利亚，E 起是弗里吉亚，F 起是利底亚，G 起是混合利底亚，A 起是爱奥利亚（小调），B 起是洛克里亚。

所以内圈的关系小调，只是“同一格换一个起点”里最常用的那一例：起点挑在第六级音上，调号一个都不用改。

是什么What is a Markov Chain

预测明天是晴是雨时，如果我们只看今天的天气，而不再关心昨天及更早的历史——这种「无记忆」的随机过程，就是马尔可夫链（Markov Chain）。它由俄国数学家安德雷·马尔可夫（Andrey Markov）于 1906 年提出，如今是概率论中最基础、应用最广的随机过程模型。

P( Xn+1 = j ｜ Xn = i, Xn-1, …, X0 ) = P( Xn+1 = j ｜ Xn = i )

这条等式就是马尔可夫性：给定「现在」，未来与过去条件独立——全部历史信息都被压缩进了当前状态里。

1

状态空间

所有可能结果的集合。例如天气模型里的 {晴, 多云, 雨}、文本生成里的词表、棋局的所有局面。

2

转移概率

从状态 i 一步跳到状态 j 的概率 pij，取值在 [0,1] 之间，且从任一状态出发的所有去向概率之和为 1。

3

转移矩阵

把全部 pij 排成方阵 P。第 i 行完整描述了「今天处于 i 时，明天去哪儿」的概率分布。

核心概念Key Properties

知道了状态和转移矩阵，一条马尔可夫链就完全确定了。下面这些性质决定了它长期「跑起来」之后会发生什么：

⚖️ 平稳分布 π

满足 πP = π 的概率向量。对遍历链，无论从哪里出发，跑得足够久后各状态的占比都会收敛到 π。

🔗 不可约

任何状态都能（经若干步）到达任何其他状态。在转移图上等价于整张图「强连通」，没有孤岛。

🕐 周期性

若回到某状态的步长只能是 d>1 的公倍数，则该状态有周期 d。不可约 + 非周期（d=1）的链称为遍历链。

↩️ 常返与暂态

以概率 1 会再次回到的状态叫常返态；有限状态的链无论怎么走，最终都会落入某个常返类里出不来。

🔢 n 步转移

Chapman–Kolmogorov 方程：P(n+m) = P(n)P(m)。想看 n 天后的分布？把矩阵自乘 n 次即可。

🕳️ 吸收态

pii = 1 的状态，一旦进入永不离开。典型例子：「游戏结束」「破产」——很多问题的终点都是吸收态。

它有什么用Applications

只要一个问题能被描述成「在若干状态之间按概率跳转」，马尔可夫链就能派上用场：

🔍 PageRank

把「用户随机点击超链接」建模为网页之间的转移，其平稳分布就是页面重要度——Google 早期排序算法的核心。

🗣️ 语音与 NLP

隐马尔可夫模型（HMM）曾是语音识别与词性标注的主力：可观测的词对应一条隐藏的「标签马尔可夫链」。

📊 MCMC 采样

马尔可夫链蒙特卡洛：构造一条以目标分布为平稳分布的链，用它的轨迹逼近平稳分布，是贝叶斯统计的发动机。

🚦 排队与性能

顾客到达/离开构成状态链，可估算队列长度与等待时间，用于呼叫中心坐席、服务器容量规划。

🧬 生物序列

DNA 碱基、蛋白质编码区/非编码区的转移概率各有特征，马尔可夫模型是基因组注释的常用工具。

🎮 游戏与生成

NPC 的行为状态机、程序化音乐与「随机文本生成器」（按上一个词抽下一个词），都是同一条链。

小结Takeaways

  • 一句话定义：马尔可夫链 = 状态空间 + 转移矩阵 + 无记忆性；知道今天，明天就完全确定了。
  • 长期行为：遍历链无论从哪个状态出发，长期占比都会收敛到唯一的平稳分布 π（πP = π）——正是上方模拟器演示的现象。
  • 局限与延伸：现实常常「有记忆」或「状态不可见」—— 记忆更长 → 高阶马尔可夫链；状态隐藏 → 隐马尔可夫模型（HMM）； 加入决策与回报 → 马尔可夫决策过程（MDP）；反过来用它采样 → MCMC。 它们都是这条「无记忆小链」长出的参天大树。

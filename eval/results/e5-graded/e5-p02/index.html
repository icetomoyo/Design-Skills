马尔可夫链

只看现在，不问过去。

明天的天气几乎只取决于今天：今天晴，明日多半仍晴；今天雨，明日转晴的机会也有限。更早以前的阴晴，影响小到可以忽略。下一步去哪，只由当前状态和一组固定概率决定，这类随机过程叫马尔可夫链。它没有记性，长期运行却会安顿进一个确定的比例。本页是一座小型观测台：你可以亲手掷这条链，看频率如何在格线里沉淀成理论值。

1906 年，A. A. 马尔可夫研究普希金《叶甫盖尼·奥涅金》中元音与辅音的交替序列，用它说明了"下一步只依赖当前状态"的模型并不需要各步独立。

全页数值均由页内脚本即时计算：你调整任何概率，矩阵、收敛表与理论值同步重算，不依赖任何外部服务。

第壹章

状态与转移：无记忆性

把系统在每个时刻所处的"情况"叫状态：天气的{晴, 雨}、掷硬币的{正, 反}、页面上读者的{阅读, 离开}。一条马尔可夫链就是一串随机状态 X₀, X₁, X₂, …，它只遵守一条规则：

P( Xn+1 = j | Xn = i, Xn−1, …, X₀ ) = P( Xn+1 = j | Xn = i )

给定"现在"，"过去"对"未来"不再提供任何额外信息。这条性质叫马尔可夫性，或无记忆性。它比"独立"弱得多：独立序列连今天都不看；马尔可夫链认真地看今天，只是看完就翻篇。

"时齐"指这些概率不随日期改变：一年后的"晴→晴"与今天的"晴→晴"是同一个数。若概率随时间变化，则是非时齐链，本页不展开。

本页只讨论有限状态、时齐的链：状态数目有限（图版一是 2 个），转移概率固定不变。这两条限制换来极强的结论：第四章的平稳分布必然存在且可达。

它与独立序列差在哪

每天独立掷一枚偏币：无论今天结果如何，"明日晴"永远是同一个概率，历史被完全无视。而图版一的链里，"明日晴"在晴天是 0.90、在雨天是 0.50：链条通过"当前状态"记住了一步历史。这正是它能产生趋势与周期的原因。

读矩阵的三件事

每行之和恒为 1：明天总要落在某个状态里（表 1 末列是页内校验）。行就是信念：读第"晴"行，即已知今天晴时对明日的完整预测。元素非负：概率没有负数。反之，任何每行为 1 的非负方阵，都是一条合法马尔可夫链。

矩阵还能回答"后天"：两步转移概率是矩阵自乘的积 P²，其 (i,j) 元 = Σk P(i,k)·P(k,j)，也就是把所有可能的中间状态加权求和。

第叁章

随机游走观测台

概率说了不算，掷出来才算。下方观测台把图版一的链交给随机数运行：掷一步按当前状态的转移概率抽取明日；自动运行按所选节奏连续观测。观测记录逐格盖印，频数板实时累计经验频率，朱红细线是第四章将推导的理论值 π。先跑起来，看它靠近。

两个值得亲手验证的现象

起点会被遗忘：重置后改为"自动运行"，无论序列从晴还是从雨开始，频数板两条横条最终停在差不多同一处。参数改变归宿：把 a 拉到 0.30、b 拉到 0.80，晴雨易势，朱红线随矩阵整体平移：链的长期行为完全写在这两个数里。

第肆章

平稳分布：无记忆，却有归宿

存在这样的概率分布 π：以 π 的比例看今日，明日按 P 转移后比例不变：πP = π。它叫平稳分布：一旦链条的总体比例到达 π，转移只是保持，不再改变。对两态链可以解出闭式：

π晴 = b ⁄ (1 − a + b) = 0.8333，π雨 = (1 − a) ⁄ (1 − a + b) = 0.1667

（代入当前滑杆的 a、b；公式推导：令 π₁ = π₁·a + π₂·b 且 π₁ + π₂ = 1。）

更惊人的是收敛：只要链不困死在某一部分状态里（本页的链做不到这一点：每个状态都能到达彼此），无论从哪个起点出发，n 步后的分布 Pⁿ 都趋于 π，表 2 的行趋同正是它。频数也一样：跑得足够久，晴天占比停在 π晴 附近。下表是一次 10,000 步的真实模拟（页内计算，可在调整 a、b 后重跑）。

归宿为何值得记

单步结局完全随机，无法预测；千万步的比例却几乎注定。随机过程的短期不可测与长期可测并存，是马尔可夫链最有用的性格：搜索引擎不必知道你会点哪个页面，只需知道链接结构，就能算出长期停留比例（这即 PageRank 的骨架）。

第伍章

边界与应用

三条边界

无记忆 ≠ 独立：链"记得"今天；连今天都不看的是独立序列。状态须穷举：若明天实际依赖前两天的天气，两态链就是错误模型，需要把状态扩成"今昨组合"（晴晴、晴雨……）来恢复马尔可夫性。时齐是假设：气候漂移会让转移概率本身移动，此时本页结论只对慢变近似成立。

把状态加到三个

快速开始

给 SQLite 加上行级同步：断网照常写，多端自动合并

Tandem 以静态库嵌进应用，每台设备直接写本地 SQLite 文件；联网后引擎按行合并多端写入，冲突可回放审计——不需要中心数据库时刻在线。

01 · 离线优先

离线不是降级模式，而是默认状态

写路径只依赖本地 WAL，延迟与在线时完全一致，不存在“离线降级”。地铁、航班、弱网下照常 INSERT / UPDATE；同步是后台任务，恢复连接后自动补发。

  • 同一行的不同字段可以在两台设备同时修改，行级 CRDT 自动合并
  • 冲突策略可插拔：LWW、字段级回调，或落盘到隔离表人工处理
  • 每次合并产出可回放日志，调试与审计有据可查

02 · 部署形态

引擎嵌在进程里，同步端点是一个二进制

核心以约 180 KB 的 C 静态库或 WASM 链接进应用：没有守护进程，没有 schema 迁移，没有 ETL。同步端点是单个静态二进制，跑在一台便宜的 VPS 或对象存储加一条 HTTP 路由之后即可。

  • 设备之间可点对点直连，也可以经中继转发
  • 传输层只追加不可变块，端到端加密可选开启
  • 一致性测试套件与参考协议实现公开在仓库

03 · 兼容性

它仍然是那个 SQLite 文件

同步元数据只增加一张表，不改动你的 schema，不引入私有存储格式——文件坏了可以用任何 SQLite 工具修复。现有查询、ORM 与 CLI 零改动。

  • JOIN、外键、触发器、FTS5、窗口函数照常工作
  • Drizzle / SQLAlchemy / sqlite3 CLI 可直接打开同一文件
  • 版本升级即替换二进制，无停机迁移步骤
